# WooCommerce Faktura z NIP Field Toggle

## Opis

Plugin dla WooCommerce dodający pole NIP z checkboxem do faktury firmowej. 
Działa tylko z klasycznym checkoutem WooCommerce. Automatycznie wyłącza checkout blokowy Gutenberg.

## Funkcjonalności

- Dodaje checkbox "Chcę fakturę z NIP na Firmę" w formularzu zamówienia
- Dynamiczne pokazywanie/ukrywanie pól firmy i NIP
- Walidacja numeru NIP
- Zapisywanie NIP w zamówieniu i profilu użytkownika
- Edycja NIP w panelu administracyjnym
- Automatyczne wypełnianie NIP z profilu użytkownika
- Wyświetlanie NIP w emailach

## Instalacja

1. Pobierz plugin
2. Wgraj do `/wp-content/plugins/`
3. Aktywuj w panelu WordPress
4. Upewnij się, że WooCommerce jest aktywne

## Wymagania

- WordPress 5.0+
- WooCommerce 3.0+
